# Nestiee 燕窩回禮 Landing Page

Tailwind CSS 版本的 Nestiee 婚禮回禮 Landing Page，風格定位：**Quiet Luxury · Effortless Elegance**。

## 檔案

| 檔案 | 說明 |
|---|---|
| `nestiee-wedding-landing.html` | 完整 HTML 頁面（含 Tailwind CDN） |

## 使用方式

### 本地預覽
直接在瀏覽器開啟 `nestiee-wedding-landing.html` 即可預覽。

### WordPress / X Theme / Cornerstone
1. 在 Cornerstone 加入 **Raw Content** 元素
2. 複製 `nestiee-wedding-landing.html` 全部內容並貼上
3. 將 CTA 連結（`href="#"`）替換為實際預約頁面或 WhatsApp 連結
